# Chronos — a countdown studio

Build a live countdown for anything — a product launch, an exam, a wedding, a
festival morning — and share it with a single link. Any date, any timezone. It
counts down, or up.

A static, single-file site. No build step, no dependencies, no tracking.

## Deploy your own

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy

## Files

- `index.html` — the whole app (markup, styles, scripts)
- `_redirects` — SPA fallback so any path serves the app
- `netlify.toml` — publish configuration

## Run it locally

Open `index.html` in any browser.
